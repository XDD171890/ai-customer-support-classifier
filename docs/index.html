AI 客服信件分類器

使用 Python + Ollama，將客服信件轉成結構化案件資訊與建議回覆。

1. 做了什麼

輸入客服信件，AI 自動判斷案件分類、優先級、問題摘要，並產生客服建議回覆。

技術：Python 3.10+、uv、Ollama、qwen2.5:3b、JSON Schema 結構化輸出。

2. 執行方式

  1. 安裝 Python 與 uv。
  2. 安裝並啟動 Ollama。
  3. 執行 ollama pull qwen2.5:3b。
  4. 執行 uv run python -m faq_assistant.main --ticket "你的客服信件"。

3. 執行結果（固定示範資料）

輸入：你好，我昨天已經付款成功，但登入後系統仍顯示尚未付款，無法使用進階功能。

分類：帳務付款優先級：高

問題摘要

使用者已完成信用卡付款，但系統仍顯示未付款，導致無法使用進階功能。

AI 建議回覆

您好，造成您的困擾非常抱歉。我們會先核對交易紀錄與帳務狀態，請您提供訂單編號或付款時間（請勿提供完整信用卡號）。確認後會協助更新付款狀態，謝謝您的耐心等候。

4. AI 使用說明

  • 模型：Ollama 本機模型 qwen2.5:3b。
  • 呼叫方式：Python 使用 urllib 呼叫 Ollama 的 /api/chat。
  • AI 能力：使用 JSON Schema 限制輸出欄位與允許值，屬於結構化輸出（Structured Output）。
  • 資料安全：預設使用本機 Ollama；請勿輸入密碼或完整信用卡號等敏感資料。
